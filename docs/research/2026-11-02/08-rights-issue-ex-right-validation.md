## 样本级公式核算

### 实际比例

```text
实际股份变动比例 = 144,173,119 / 387,280,800
                 = 0.3722702468080008...
实际每 10 股配售 = 0.3722702468080008... × 10
                   = 3.722702468080008...
公告展示值       = 3.722702（每 10 股）
```

公告的 `3.722702` 与计算结果在所示小数位一致；不能把公告展示值当成无限精度比例，也不能用计划值 `0.4` 替代实际值。

### 认购率与资金复算

```text
144,173,119 / 154,912,320 = 0.930675617020002... = 93.067561702...%
144,173,119 × 3.36          = 484,421,679.84 元
144,173,119 + 387,280,800   = 531,453,919 股
```

三项均与公告披露值一致（认购率按公告展示精度比较）。这只是公告字段之间的算术一致性，不是独立审计。

### 除权参考价

本事件无现金红利，按深交所 2026 年《交易规则》`4.4.2` 的结构：

```text
除权参考价 = [(前收盘价 - 现金红利) + 配股价格 × 股份变动比例]
             / (1 + 股份变动比例)
```

使用 `2026-08-12` 的腾讯 bfq 收盘价 `5.230`、配股价格 `3.36`、实际比例 `0.372270246808...`：

```text
实际比例参考价 = (5.230 + 3.36 × 0.372270246808...)
                 / (1 + 0.372270246808...)
               = 4.722705344920036...
               ≈ 4.723（三位小数）
```

若错误地使用计划比例 `0.4`：

```text
计划比例参考价 = (5.230 + 3.36 × 0.4) / 1.4
               = 4.695714285714...
               ≈ 4.696（三位小数）
```

腾讯 qfq 在 `2026-08-12` 的收盘价为 `4.723`，与实际比例公式的三位小数结果一致；与计划比例结果相差约 `0.0273` 元。该样本级核算支持“实际比例而非计划比例”这一解释方向，但不证明腾讯算法。

## 可复用结论

1. 配股事件账本必须同时保存“计划比例”和“实际股份变动比例”；计划 `10 配 4` 不等于实际除权比例。
2. 实际比例至少可由 `实际认购股数 / 登记日总股本` 复算；还应保存计划可配售上限、认购率、配股价格、登记日、除权日和发行结果公告 ID。
3. 事件账本中的公式项应保存为 `issue_price × actual_share_change_ratio`，而不是只保存 `issue_price` 或只保存计划比例。
4. 腾讯 `djr/cqr` 可做日期线索；`fh_sh` 为空不能恢复配股价格/比例，不能把行情附属字段当作完整公司行动账本。
5. “日期对齐 + 公告字段复算 + 规则公式 + qfq/bfq 边界”可以作为数据质量检查组合，但只能形成样本级证据，不能替代 PIT 认证。
