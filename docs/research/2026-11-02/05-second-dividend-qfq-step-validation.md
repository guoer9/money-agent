## 价格边界检查

### 事件 A：2024-06-18 → 2024-06-19

原始价（bfq）与前复权（qfq）的收盘位置：

| 日期 | bfq 收盘位置 | qfq 收盘位置 |
| --- | ---: | ---: |
| 2024-06-18 | 1521.500 | 1387.161 |
| 2024-06-19 | 1501.000 | 1397.537 |

- bfq 收益：`-1.347355%`
- qfq 收益：`+0.748003%`
- qfq/bfq 比值：`0.911706211 → 0.931070620`
- 比值乘法台阶：约 `+2.123975%`

### 事件 B：2024-12-19 → 2024-12-20

| 日期 | bfq 收盘位置 | qfq 收盘位置 |
| --- | ---: | ---: |
| 2024-12-19 | 1551.010 | 1447.547 |
| 2024-12-20 | 1522.000 | 1442.419 |

- bfq 收益：`-1.870394%`
- qfq 收益：`-0.354254%`
- qfq/bfq 比值：`0.933293144 → 0.947712878`
- 比值乘法台阶：约 `+1.545038%`

### 可写结论

在两个真实分派事件中，qfq/bfq 比值都在**公告指定的除息日边界**发生变化，且方向、事件位置可重复。第一个事件的台阶约 2.12%，第二个约 1.55%，与现金分红比例处于同一数量级。

### 不可写结论

- qfq 与 bfq 在共同日期上的绝对比值不等于 1，说明两者存在整体价格尺度差；不能用“qfq 收盘 / bfq 收盘”直接恢复复权因子。
- 台阶幅度不等于公告现金比例本身，不能把差额解释为供应商公式；缺少官方公式和基准日信息。
- 不能用这两个样本证明全市场复权一致、历史 qfq 永不回写或已满足 PIT。
- 不能把这组价格变化写成真实投资收益；未建模持有期、税费、分红到账和交易执行。

## 事实、发布方陈述与本项目推断

### 来源支持的事实

1. 2024 年中期权益分派公告明确给出 2024-11-27、2024-12-19、2024-12-20 和 23.882 元/股。
2. 腾讯同事件响应明确返回 `djr=2024-12-19`、`cqr=2024-12-20`、`fh_sh=238.82`。
3. 两个已核验事件中，公告日期/比例与腾讯附属字段均可重复对齐。
4. 两个事件的 qfq/bfq 比值都在公告除息日边界发生台阶。
5. 重复下载同一 2024-06 窗口的 qfq 解析行在本轮仍一致，但原始响应哈希可不同。

### 发布方/供应方陈述

- 腾讯附属字段的含义是依据字段值和公告对照做出的项目侧归一化，不是腾讯公开文档。
- 巨潮查询接口只是公告发现入口；事件日期与比例最终以公告 PDF 为准。

### 本项目推断（尚未代码验证）

1. 事件账本应保存：公告 ID、原文 URL、公告日、股东大会日、登记日、除息日、发放日、每股现金比例、每 10 股原始值、换算规则、事件类型、是否差异化分红。
2. 事件校验规则应先比较“公告字段 ↔ 腾讯附属字段”，再比较“事件日期 ↔ 比值台阶位置”；两步证据不可合并成“已复算复权因子”。
3. 若 `fh_sh` 与公告每股比例不满足 `fh_sh = 每股比例 × 10`，应记录异常而不是静默接受。
4. 复权价格审计应同时保存 qfq、bfq、hfq 的原始响应和规范化行；只保存一个口径无法判断尺度变化来源。
5. 当前证据还不足以选定复权公式，因此不应在策略代码中实现“由现金比例直接重构 qfq”的逻辑。

## 可复用结论

- 两个真实现金分派事件都支持：股东大会日、登记日、除息日、发放日是不同字段。
- 腾讯 `djr/cqr/fh_sh` 可作为事件交叉校验线索，但不能替代公告或公开公式。
- qfq/bfq 比值在除息边界的台阶是**可重复的可观测信号**；台阶幅度与现金比例同数量级，但不能直接当作现金比例。
- 审计应同时保存公告 PDF 哈希、腾讯原始 JSON 哈希、规范化价格行哈希和字段换算规则。
- 事件账本先通过字段对齐，再讨论价格调整；不得把“字段对齐成功”写成“PIT 或复权公式已验证”。
