## 研究纪律

1. 每轮只推进一个可验证的子任务。
2. 结论必须附上本机命令、时间、证据路径与限制。
3. 经典 baseline、模拟数据、真实 LLM 生成、最终测试严格分开。
4. 无模型凭据时记录未验证，不用经典结果替代。
5. 不修改根目录 `qlib_trading`；不覆盖其他并行改动。
6. 不创建 Codex goal，不设置 token budget。

## 当前研究模式

每 30 分钟围绕一个窄问题做网络资料研究，持续 24 小时，优先形成可追溯的 LLM 量化因子系统优化语料。系统验收与语料研究并行，但不再让调度器默认推送验收测试任务。

## 当前唯一优先方向

下一轮唯一优先方向：继续围绕因子生成与代码校验检索一手来源，重点确认如何把生成代码的语法/运行/数值域检查、随机性和失败样本纳入 run manifest，并区分“代码可执行”与“因子定义、标签和回测协议一致”；只做资料研究，不修改策略代码，不运行最终测试。
