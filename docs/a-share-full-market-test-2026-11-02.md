## 范围与可重复入口

这次“全量”指从上交所、深交所、北交所当前证券名单出发，逐证券获取可得到的新浪原始日线；原文保留来源可取得的全部历史，规范化文件限定为 **2015-01-01 至 2026-10-30**。固定结束日避免在本次长耗时采集中混入尚未统一确认的当日快照，不限制原始响应归档。没有计算因子、标签、收益或保留测试区间的评价指标。

交易所三站独立下载的代码集合与腾讯全量分页完全一致：5,577 个代码。剔除 `sh689009` 这只 CDR 后，目标为 **5,576 只 A 股**：沪市 2,317、深市 2,905、北交所 354。官方名单还提供上市日期，已保存为证券主表。这个集合不包含全部历史退市证券，不能称为无幸存者偏差的历史全市场。

隔离目录相对产品根目录：`runtime/verification/20261102-ashare-full/`。产品 `.venv`、`runtime/data`、历史基线与实验身份不变；AKShare 1.18.88、pandas 2.3.3、pyarrow 25.0.1 只在验证环境使用。


采集为单连接，发起间隔至少 0.5 秒；每次网络调用由子进程执行，父进程 12 秒硬截止。403/429 停止来源，连续三次网络失败打开熔断；未完成项和最近成功的文件留在独立目录，不静默补零或换源拼接。首轮多年补库与“一分钟小池增量更新”的目标分别计时。

## 为什么前一次取不到

新浪前复权因子在续测中恢复：curl 与 Python 请求均返回 HTTP 200，随后 30 只试点的独立因子文件全部取得。原始日线与股本接口已经分开采集，不再因为附加股本请求失败丢弃基础 K 线。没有证据支持“新浪因子永久不可用”或“需要付费才能获取”的结论。

东财失败的初始现场是 DNS 返回 `198.18.*` 地址、路由经过 `utun6`，curl 与 Python 均出现 TLS 连接关闭或读超时，没有收到行情 JSON。随后 DNS 返回公网地址、路由变为 `en0`，相同参数的请求返回 HTTP 200 和 57 条日线，HTTP 约 0.18 秒；实际 `ak.stock_zh_a_hist` 调用也成功。

**用户确认在测试期间主动开关 VPN 以访问外网。** 这与上述路径变化及东财恢复一致，采集错误应结合当时网络环境判断。没有改动全局 VPN、代理、DNS、路由或证书校验；也没有绕过验证码、403/429 或提高请求量来恢复。具体哪条 VPN 规则造成某次连接关闭没有单独隔离，不把每个网络错误都归结为同一原因。

曾对一个由本地网络应用持有的候选监听端口做 CONNECT 诊断，得到本地 404。它没有被确认为可用 HTTP 代理，该结果不代表东财返回 404，也不作为上游可用性证据。后续国内行情采集与 GitHub、论文、模型等外网访问应分别制定网络路径；仅设置 `NO_PROXY` 不足以保证绕过系统 TUN。

训练期交叉核对：浦发银行 2015 年一季度在两源匹配 57 个交易日，OHLC 完全一致。新浪成交量为股，东财为手；转成股后最大差异为 56 股，未强行抹平。复权、公司行为及可交易性仍需独立验收。

## 数据质量的解释边界

- 下载成功、解析成功、价格质量通过、研究可用分别统计；不能以 HTTP 200 代表论文数据已经合格。
- 源数据包含零开高低价、零量或较早的最后交易日期，保留原文与标记，不自动填充或断言都是漏抓。
- 部分北交所证券的响应包含在当前交易所上市前的历史，可能涉及新三板阶段；证券主表日期之前的数据不能自动算作 A 股板块实验样本。
- 交易日历差额可能来自停牌或源内遗漏，需交易状态进一步解释。停牌不填为可交易记录。
- 本轮仅抽样 30 只独立新浪因子资产；全量原始日线不等于全量复权研究集，不覆盖全部退市历史或严格历史时点可得性。
