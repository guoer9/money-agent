## 已接通的流程与尚缺的连接

```text
命令行触发行情下载
  → 原始 JSON / 指纹
  → 清洗 / 共同交易日历
  → panel.parquet / manifest.json
  → 页面或 API 提交 baseline 任务
  → SQLite 队列 / 独立 worker
  → 六个经典因子的验证集评价
  → baselines.json
  → API / Vue 页面 / JSON 导出
```

行情获取仍是单独的命令行步骤。前端“刷新研究数据”重新读取后端状态与已有归档，不会重新向行情供应方抓取。worker 当前只有 baseline、llm 两种模式，没有采集任务，也没有自动串联“采集完成后复算”的编排。尚无定时增量更新、完整多源容错或行情质量告警闭环。

`thesis.rd_adapter.run_research` 的真实适配器尚未实现，模型环境未就绪；真实生成和反馈、候选冻结及独立最终测试均未完成。保留测试日期不等于已完成最终测试。

当前行情是固定股票池的供应方前复权快照，尚未完成历史时点股票池与逐事件复权验证。每标的 640 根日线限制、10 条缺失股票交易日记录均在清单中披露。当前分层收益是统计评价，尚不包含费用、滑点及可交易性约束。
