# RD-Agent 因子研究工作台

用户已要求直接执行，以系统质量和论文为目标，前端展示为重点。本设计继承前轮 RD-Agent 主体选择和数据/评价/隔离原则，改为 React 独立研究工作台；不再以 Streamlit 作为主界面。不依赖日程审批。

目标：真实多股票数据→可检查的因子→日截面评价→验证反馈→冻结测试→中文报告，全部能在前端查看。上游 RDLoop 和 FactorTask 必须实际使用，适配代码与上游分开。离线经典因子、真实模型调用和归档回放明确区分。

前端：React、TypeScript、Vite，浅色研究工作台，深绿强调色；总览、数据管理、研究工作台、因子档案、实验对照、论文材料六个视图。公式、代码、阶段、数据范围和评价解释可读；错误、空数据、连接失败和未配置模型均有实际状态。图表支持切换区间与导出，测试集在冻结后独立运行。

后端：FastAPI + SQLite + Parquet。耗时工作在独立 worker 进程；HTTP 查询不执行研究。运行事件持久化，可刷新恢复。初期单个活跃研究任务，重复提交幂等。没有密钥时明确不可调用，不自动伪造生成结果。

计算：受限表达式 AST，不执行任意 LLM Python。表达式对应生成固定 Python，限制算子、字段、窗口和滞后，校验模型提供代码一致性。运算按股票和日期边界处理。默认 t 收盘生成，t+1 收盘进入，t+2 收盘退出；按退出日期 purge 分段。IC Pearson、RankIC Spearman、ICIR 样本标准差；按日五分层，缺失状态不能转成零。真实交易收益与统计分层分开。

数据：公开接口获取带日期记录，保留原始响应和来源说明；质量报告要求 ≥10000 条真实有效记录。原价/复权价、单位和停牌分开记录。最终测试数据和标签不进入模型上下文。经典基线、单次生成、反馈改进同口径比较。

风险边界：数据接口不可用时尝试另一公开来源或有来源的用户数据，绝不模拟顶替；RD/Qlib 兼容采用实际导入和调用测试锁定；模型缺凭据时完成其他功能并如实标记真实反馈待验证；论文实验章节只引用已有产物，待验内容保留明确状态。

论文同步保存需求、架构、算法、接口、测试和真实实验图表。学校任务书正文不少于12000字；字数和规范最终逐项检查，负结果也如实呈现。
