# AlphaLab v1.2 页面设计与流程规划

用户在 2026-11-01 已批准方向并授权规划后直接开发和发布 v1.2。此前暂停已解除，无需再询问实施方式。原 qlib_trading 保持原样；产品在独立仓库 rdagent_thesis 开发。

## 作品与版本边界

作品为“基于大语言模型的智能股票量化因子生成与评估系统”。v1.2 的可验收闭环：真实行情→经典因子→确定性评价→精美研究总控→联动工作台→实验归档与导出。RD-Agent 真实接线与模型可用性独立记录，缺凭据时明确未配置，不能把经典复算当作模型生成。完整毕业研究仍需真实反馈、冻结候选和独立测试，版本发布不意味着这些实验已完成。

参考采用：Koyfin 多面板组织、TradingView 图表/表格联动、StockAnalysis 清晰搜索。用户提供的抓取结论视为二手设计证据，营销页框架不能代表产品栈；Bloomberg 未进入产品不做推断。代码底座采用已固定的 SoybeanAdmin 源码，MIT 许可和上游指纹保留。不引入拖拽编辑器、实盘、新闻/IPO 等无关业务。

## 页面信息架构

固定左侧 76px 图标导航，顶栏品牌/服务状态/刷新/全屏/北京时间；内容区最大宽约 1680px。深蓝黑背景，温和灰蓝面板，荧光绿为研究强调色，橙色为待配置/质量提示。数字等宽，中文正文清晰，正文至少 13px、次要标注至少 11px；交互有可见焦点。避免无意义装饰图表。

| 页面 | 主内容 | 操作与验收 |
|---|---|---|
| 研究总控 | 四项真实摘要；主 IC 图；四阶段研究流程；经典因子表；五分层收益 | 因子切换联动全部面板；IC/Rank IC切换；可全屏与退出；显示归档日期和区间 |
| 数据资产 | 来源、清洗质量、股票池、日期范围、指纹、训练/验证/测试 | 明确固定股票池偏差和复权口径，不宣称实时或无偏历史成分 |
| 因子实验室 | 可搜索因子列表、含义、表达式、指标、IC/分层/分布图、计算入口 | 列表选择同步图表和说明；对象选择写URL，刷新保持 |
| 研究进化 | 五步骤、引擎状态、自然语言研究入口、真实父子对照或明确空态 | 缺模型禁止真实调用；经典模式明确标注；只使用验证集反馈 |
| 实验档案 | 状态表、模式、ID、日期、详情抽屉、事件和结果 | 独立worker、SQLite持久化、幂等提交、刷新恢复 |
| 论文材料 | 数据/经典评价/反馈/独测证据状态、评价协议、实验材料导出 | 只导出已完成真实结果，不导出密钥和最终测试标签 |

## 总控布局

第一行是页面标题、研究归档状态和新建研究。第二行四个摘要，依次为行情记录、经典因子数、选中因子的 Rank IC、有效覆盖率。第三行主图约占 2/3，研究进程约占 1/3；第四行因子表约占 2/3，分层图约占 1/3。末尾保留数据可追溯入口和同步时间。1366/1440宽完整展示，1024宽双列/紧凑，窄屏单列和表格局部滚动。

工作台与展示模式共用数据、选中对象和协议；展示模式隐藏侧导航，扩大图表阅读空间。浏览器原生全屏不可用时使用查询参数 display=1 进入同等布局，有可见退出入口。禁止把历史归档标为实时行情。

## 状态与交互

URL query view=overview|data|factors|feedback|runs|reports，factor=因子ID，display=1可选。选因子同时更新主曲线、分层、指标、表达式和说明。区间限定完整归档验证期，v1.2 不提供会误导为重新评价的前端日期截断。表格搜索是展示筛选，不产生研究指标。

连接中显示加载；接口失败显示重试与上次数据标识；空归档解释为何为空；非法/失效因子不绘制零值。每项任务显示 queued/running/complete/failed；研究执行器不在线则不可提交，凭据未配置则不可提交 LLM 模式。禁用按钮旁有可读原因。反馈尚未执行时保留完整空态而非伪对照。

## 研究与数据协议

面板索引 (datetime,instrument) 唯一，统一日历，不前向/反向填补行情。t收盘因子，t+1收盘进入，t+2收盘退出；分段按退出日期purge。日截面Pearson/Spearman，ICIR使用日IC样本标准差，缺失null。分层为统计性持有期均值，不代表含费用的可交易组合。

原始响应、哈希、来源、下载时间、清洗报告和≥10000真实有效多股记录归档。baseline只评价validation，最终测试不参与筛选/模型上下文；发布页面不得显示独测已完成。固定股票池、复权局限和交易费用等限制明确说明。

API提供 Overview {archive,runs,environment,final_test,server_time,version}，archive复用前端 research.ts 契约；plain JSON，与上游演示code=0000协议隔离。GET /api/overview、/datasets、/factors、/runs、/runs/{id}、/reports/export；POST /api/runs 接收幂等键。请求进程不执行研究；独立worker单活跃任务，持久事件。产物采用原子写入。只读浏览无需登录，默认仅监听127.0.0.1。

## 实施、验收和发布流程

设计与契约固化→数据/服务与前端并行实施→真实归档接入→数值测试/API测试/前端类型与构建→真实浏览器检验1440、1024和空错态→独立审阅→修复→生成v1.2.0源码/构建/实验归档发布包与校验和、本地Git标签。

当前仓库无远程发布目标，因此发布产物在本地 releases/；不虚构公网部署或远程Release。发布包不包含密钥、虚拟环境、node_modules、研究仓库；附运行指南、设计/流程、测试证据、许可证及已知限制。提供统一启动入口与真实离线归档，演示不依赖行情接口持续在线。

验收必须：六页面可访问；因子联动；搜索；全屏退出；真实图表；基线任务提交/执行/刷新恢复；无凭据明确不可用；导出；数值与API测试通过；类型/构建通过；无浏览器致命错误；证据完整。RD-Agent实测状态与真实LLM实验分别披露。
