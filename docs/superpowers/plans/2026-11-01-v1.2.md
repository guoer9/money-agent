# AlphaLab v1.2 Implementation Plan

> **For agentic workers:** Use executing-plans for the frontend critical path and dispatching-parallel-agents for disjoint backend work; one independent final review. User already authorized direct execution.

**Goal:** 发布具有六个精美页面、联动研究工作台、真实行情评价和可追溯实验的 v1.2.0。
**Architecture:** 固定 SoybeanAdmin/Vue 3 与 Pinia/ECharts；FastAPI、SQLite与独立worker；真实行情Parquet与评价JSON；RD-Agent适配单独披露。
**Spec:** ../specs/2026-11-01-v1.2-design.md

## Global Constraints
- 只在 rdagent_thesis 开发，原系统和研究克隆不改。
- 最终测试不进入验证反馈；不可用指标null；不伪造模型与收益。
- 真实归档≥10000条；上线Mock移除；默认服务127.0.0.1。
- 框架源码和MIT保留；发布包不含凭据与环境目录。

## Review Focus
- 乱序、缺日、常数因子和分段边界：数值结果不可串股/泄漏。
- 幂等键冲突、无worker、重复claim：不重复或遗失任务。
- API断开、空归档、模型未配置：页面有可理解状态。
- 刷新/返回/因子切换：URL状态、指标、两图与说明一致。
- 归档、页面和导出：协议/版本一致，最终测试不能伪标完成。
